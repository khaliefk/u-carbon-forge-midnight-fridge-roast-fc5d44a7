One line, one joke: a roast of a smart fridge that locks itself after
midnight, like a nightclub bouncer who never lets you in.

## What it does

`main.py` (Python 3, stdlib only) writes a single roast line to
`/output/entry.txt`. Nothing else runs, nothing is read from the network,
no secrets, no dependencies.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
